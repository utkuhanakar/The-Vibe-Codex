# ⚡ Productivity & Workflow Tools

> "The best tool is the one that stays out of your way."

### 🏆 Best for Use Case
- **Best for Task Management:** [Logseq](https://github.com/logseq/logseq) or [Obsidian](https://obsidian.md).
- **Best for Documentation:** [Docusaurus](https://github.com/facebook/docusaurus).
- **Best for Focus:** [Pomotroid](https://github.com/Splode/pomotroid).

### 🛠 Tools
- [Microsoft PowerToys](https://github.com/microsoft/PowerToys) — System utilities to maximize productivity.
- [Espanso](https://github.com/espanso/espanso) — Cross-platform Text Expander written in Rust.
- [Fzf](https://github.com/junegunn/fzf) — A command-line fuzzy finder.
