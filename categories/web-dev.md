# 🖥️ Web Architecture & Fundamentals

From understanding the DOM to scaling applications with TypeScript and React. This list focuses on the *why* behind web technologies, not just the *how*.

## 🧱 The Core (HTML / CSS / JS)

- [You Don't Know JS](https://github.com/getify/You-Dont-Know-JS) ![Free](https://img.shields.io/badge/Free-Success?style=flat-square) ![Book](https://img.shields.io/badge/Resource-Book-blue?style=flat-square)
  - A book series diving deep into the core mechanisms of the JavaScript language.
- [CSS Architecture (BEM)](https://github.com/getbem/getbem.com) ![Methodology](https://img.shields.io/badge/Methodology-Standard-orange?style=flat-square)
  - Methodology that helps you to create reusable components and code sharing in front-end development.

## ⚛️ Component Logic (React & Ecosystem)

- [React](https://github.com/facebook/react) ![Framework](https://img.shields.io/badge/Frontend-Library-blue?style=flat-square&logo=react)
  - The library for web and native user interfaces. Focus on understanding Props, State, and Hooks.
- [Zustand](https://github.com/pmndrs/zustand) ![State](https://img.shields.io/badge/State_Management-Lightweight-yellow?style=flat-square)
  - A small, fast, and scalable bearbones state-management solution using simplified flux principles.

## 🛡️ Type Safety (TypeScript)

- [TypeScript Tutorial](https://github.com/remix-run/remix) ![Official](https://img.shields.io/badge/Official-Microsoft-black?style=flat-square)
  - A starter template for TypeScript and Node with a detailed README describing how to use the two together.
- [Type Challenges](https://github.com/type-challenges/type-challenges) ![Practice](https://img.shields.io/badge/Practice-Challenge-red?style=flat-square)
  - Collection of TypeScript type challenges with online judge.

## ⚙️ Backend & API (Node.js)

- [Node.js Best Practices](https://github.com/goldbergyoni/nodebestpractices) ![Architecture](https://img.shields.io/badge/Architecture-Must_Read-purple?style=flat-square)
  - Comprehensive compilation of Node.js best practices, focusing on architecture and security.
- [Express](https://github.com/expressjs/express) ![Framework](https://img.shields.io/badge/Backend-Framework-green?style=flat-square&logo=nodedotjs)
  - Fast, unopinionated, minimalist web framework for Node.js.
