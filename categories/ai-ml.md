# 🤖 Artificial Intelligence & Machine Learning

A curated list of frameworks, models, and tools for integrating AI into systems and building autonomous agents.

## 🧠 LLM Frameworks (App Building)

- [LangChain](https://github.com/langchain-ai/langchain) ![Framework](https://img.shields.io/badge/Framework-Production-blue?style=flat-square)
  - Building applications with LLMs through composability. Best for complex chains of thought.
- [LlamaIndex](https://github.com/run-llama/llama_index) ![Data](https://img.shields.io/badge/Data-RAG-purple?style=flat-square)
  - Data framework for your LLM applications. Essential for connecting AI to private databases or PDFs.

## ⚡ Autonomous Agents

- [AutoGPT](https://github.com/Significant-Gravitas/AutoGPT) ![Agent](https://img.shields.io/badge/Agent-Autonomous-yellow?style=flat-square)
  - An experimental open-source attempt to make GPT-4 fully autonomous.
- [BabyAGI](https://github.com/yoheinakajima/babyagi) ![Agent](https://img.shields.io/badge/Agent-Task_Driven-orange?style=flat-square)
  - An AI-powered task management system.

## 🛠️ Vibe Coding & Control

- [Guidance](https://github.com/microsoft/guidance) ![Official](https://img.shields.io/badge/Official-Microsoft-black?style=flat-square)
  - A guidance language for controlling large language models. Forces the AI to output exactly the JSON or structure you need.
- [OpenAI Cookbook](https://github.com/openai/openai-cookbook) ![Examples](https://img.shields.io/badge/Resource-Examples-success?style=flat-square)
  - Example code and guides for accomplishing common tasks with the OpenAI API.
