# 🛠 Developer Tools

### 🔥 Top Picks
- [neovim](https://github.com/neovim/neovim) - Modern and highly customizable code editor.
- [deno](https://github.com/denoland/deno) - Secure runtime for JS and TS.
- [bat](https://github.com/sharkdp/bat) - Better version of `cat` with syntax highlighting.

### 📦 Terminal & Workflow
- [cli](https://github.com/cli/cli) - Official GitHub CLI tool.
- [ripgrep](https://github.com/BurntSushi/ripgrep) - Fast search tool.
- [lazygit](https://github.com/jesseduffield/lazygit) - Simple terminal UI for git.
- [starship](https://github.com/starship/starship) - The minimal, blazing-fast, and infinitely customizable prompt for any shell!
