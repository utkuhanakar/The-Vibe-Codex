# 🌐 Web Fundamentals & Architecture

From understanding the DOM to scaling applications with TypeScript and React. This list focuses on the *why* behind web technologies, not just the *how*.

## 🧱 The Core (HTML / CSS / JS)

- [You Don't Know JS](https://github.com/getify/You-Dont-Know-JS) - A book series diving deep into the core mechanisms of the JavaScript language.
- [CSS Architecture (BEM)](https://github.com/getbem/getbem.com) - Methodology that helps you to create reusable components and code sharing in front-end development.

## ⚛️ Component Logic (React & Ecosystem)

- [React](https://github.com/facebook/react) - The library for web and native user interfaces. Focus on understanding Props, State, and Hooks.
- [Zustand](https://github.com/pmndrs/zustand) - A small, fast, and scalable bearbones state-management solution using simplified flux principles.

## 🛡️ Type Safety (TypeScript)

- [TypeScript Tutorial](https://github.com/microsoft/TypeScript-Node-Starter) - A starter template for TypeScript and Node with a detailed README describing how to use the two together.
- [Type Challenges](https://github.com/type-challenges/type-challenges) - Collection of TypeScript type challenges with online judge.

## ⚙️ Backend & API (Node.js)

- [Node.js Best Practices](https://github.com/goldbergyoni/nodebestpractices) - Comprehensive compilation of Node.js best practices, focusing on architecture and security.
- [Express](https://github.com/expressjs/express) - Fast, unopinionated, minimalist web framework for Node.js.
